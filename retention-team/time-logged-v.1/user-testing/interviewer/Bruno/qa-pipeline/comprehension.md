# Stage 1 — Comprehension and Orientation

## What this document is
A moderated usability-test transcript for an unreleased Hubstaff prototype, "Time Logged" — a redesign of the Timesheets ("View and Edit") page that adds a manager multi-member table view and batch add-time functionality. The session covers a manager-role task flow followed by a regular-user-role task flow, plus closing open-ended questions about naming, missing functionality, and rollout.
