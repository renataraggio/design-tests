# Stage 1 — Comprehension and orientation

## What this body of text is

A moderated usability test (Fireflies transcript, 2026-07-06) of an unreleased Hubstaff prototype called
"Time Logged" — a redesign of the Timesheets page. The redesign adds: (1) a manager multi-member view
(see/filter time across the whole team, add time to multiple members and multiple time entries at once,
batch actions like reassign/delete), and (2) a per-member "Add Time" dialog with fields for date, time
range, project, to-do, reason (mandatory), notes, and a billable toggle. The old page ("View and Edits")
only supported single-member, single-entry interaction. The session walks the participant through manager
tasks (filter team time, bulk-add time, drill into one member's time log, navigate back to multi-member
view, view another member's time, view own time) and then two regular-user tasks (add own time, view own
time weekly), followed by closing/wrap-up questions about page naming, terminology (Time logged vs. Time
tracked vs. Time worked), the "what's coming" pop-up copy, and the value of the multi-member view.
